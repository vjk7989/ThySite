# Buckleson website guide

This Astro, Tailwind, Preline, Anime.js, and Starlight project adapts an existing template into Buckleson’s public website. It is English-only and deployed to GitHub Pages under `/ThySite`.

Public information architecture:

- `/` — positioning, trust architecture, control boundaries, engagement process.
- `/products/` — Platform overview.
- `/products/hyper-tern/`, `/products/hyper-abs/`, `/products/hyper-0x/`, `/products/hyper-wallet/` — bounded module detail pages.
- `/services/` — AI assessment, secure inference, custom AI development, and operating design.
- `/blog/` — Insights field notes and risk library.
- `/welcome-to-docs/` — English platform overview.

Use the shared path helpers for every internal link. Keep claims qualified, customer-independent, and traceable to `docs/site-content-map.md`. Do not introduce authentication, forms, backends, customer proof, pricing, or unsupported security/privacy guarantees.
